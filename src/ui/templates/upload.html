What happens next

{% if key_configured %}
After upload you'll see a preview and a Run live button. Clicking it makes one real API call against your xAI account, costing roughly $0.01–0.10. Nothing runs until you confirm — the button opens a browser confirmation dialog first.
{% else %}
No API key is configured yet. Add one in the API key panel on the right — takes a paste and a click. Then upload; the per-file Run-live gate still requires an explicit confirmation before any call fires. Terminal users can add XAI_API_KEY=xai-... to .env directly instead.
{% endif %}
Why a live call? The system replays recorded responses for the 20 invoices it has seen before, at zero cost. A new invoice has no recording, so the model has to actually run once.
